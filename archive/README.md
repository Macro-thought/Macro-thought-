## wn18rr-repro：WN18RR 上的 TransE / RotatE 复现

- 内容：两个经典知识图谱补全基线在 WN18RR 上的复现，测试集 MRR 0.2229（TransE）与 0.4754（RotatE），
  与原文相对误差 1.4% / 0.12%。
- 顺带解决了原代码在 NumPy 2.x + Windows 下的三处不可运行问题（`np.in1d` 被移除、DataLoader 多进程死锁、
  无随机种子），修复脚本幂等。
- 详细的配置取舍（为什么把 RotatE 的负采样从 1024 降到 512）写在 `wn18rr-repro/README.md`。
