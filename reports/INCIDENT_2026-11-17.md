# 事故记录：夜间审计回执误判「全部通过」

日期：2026-11-17　｜　发现：竣工验收（2026-11-17 12:40）　｜　状态：已修根因，待重生成验证

## 一、发生了什么

`reports/night_audit_2026-11-17.md` 是 11-17 凌晨的审计回执，第 14 行写：

> **闸门总判定：全部通过**

而同一份文件第 9 行的 G0 末行是：

> 判定： {'c': 'fail', 'b': 'fail', 'd': 'partial', 'a': 'unverified'}

即：**数据可行性四项里两项不达标、一项部分、一项未测，回执却给出"全部通过"。**

## 二、根因

`scripts/audit_night.py` 第 69 行（修复前）：

```python
gate_ok = all(c == 0 for _, _, c, _ in gate_rows)
```

它只看子进程退出码。而 `scripts/probe_t10.py` 是"探针"性质——**只要四个探针跑完就返回 0**，合格与否写在 `data/probe_t10.json` 的 `verdicts` 里，退出码不承载这个信息。
于是 G0 的语义判定从未进入 `gate_ok`，第 91 行就打印了"全部通过"。

原作者在第 16 行其实写了注："G0 的退出码 0 只表示探针跑完了，不表示数据合格——四道闸门里只有 G0 需要人来判"。**但机器判定没有把这句编码进去**，靠人读注的机制在凌晨失效了。

## 三、影响面

| 受影响 | 说明 |
|---|---|
| 决策依据 | 若有人据此认为"数据可行性已通过"，会把 MERGE 合成对、RESTRICT 非时间收窄当成可忽略的细节 |
| 下游报告 | `t13_ops.md`、`t14_labels.md` 与回执同源生成，但这两份只陈述事实，未复述总判定，**内容不受污染** |
| 数字本身 | 探针数字、图指纹、标签统计**均未受影响**——错的是判定语句，不是数据 |

## 四、已做的处置

1. 原回执原样存档为 `reports/night_audit_2026-11-17_asfound.md`（不删、不改数字），作为事故证据。
2. 修 `scripts/audit_night.py`：
   - 新增 `g0_verdict()`，直接读 `data/probe_t10.json` 的 `verdicts`；
   - `gate_ok` 改为「G0 四项全 pass + G1–G3 退出码 0」；
   - 报告按实际结果输出「闸门总判定：未通过（…）」，并固定标注「G0 不通过 + 按 D1/D2/D4 缩范围继续，不得宣称数据可行性已通过」；
   - 退出码随 `gate_ok` 变化（不通过时返回 1）。
3. 修 `ops/apply_ops.py` 的 `built_at`：指纹不变则沿用旧时间戳，避免每次审计都让 7 份图字节变化、`git status` 永远脏。
4. 本文件写下结论：**在修复并重生成之前，任何材料不得引用"闸门全部通过"。**

## 五、纪律（写进组内规范）

- **退出码只能表达"程序有没有崩"，不能表达"结果合不合格"。** 任何"合格/不合格"的判定，必须落成一个机器可读的字段（如 `verdicts`），并由汇总脚本读取，不能写在自然语言末行里靠人看。
- 报告是生成物：`reports/` 下除 `t11_check.md` 外都由脚本产出，**手改会在下次复跑被覆盖**。要改文案就改生成器模板。
- 汇总脚本的判定语句，必须与它引用的明细行同源计算，不允许一个来自退出码、一个来自文本。

## 六、复核方式

```bash

python scripts/audit_night.py; echo "EXIT=$?"     # 期望 EXIT=1
grep -c "闸门总判定：全部通过" reports/night_audit_2026-11-17.md          # 期望 0
grep -c "闸门总判定：全部通过" reports/night_audit_2026-11-17_asfound.md  # 期望 1（证据）
grep -c "闸门总判定：未通过" reports/night_audit_2026-11-17.md           # 期望 1
grep -c "G0 不通过" reports/night_audit_2026-11-17.md                    # 期望 1
git status --porcelain data/                                            # 期望为空（built_at 不再刷新）
```
