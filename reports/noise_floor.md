## 三、与主表对照

| 项 | 值 | 来源 |
|---|---|---|
| 主表 B2 FR（v1 vs v2） | 0.138（69/500） | `reports/metrics_all_live.md` |
| 主表 B2 FFR | 0.113（49/435） | 同上 |
| 噪声 FR（v1 跑两遍） | **0.180** | 本报告 |

读法：噪声是「同一张图重复问」的抖动。主表 FR 若显著高于噪声，才能归因于图变更；若两者接近，说明所谓翻转大部分是模型自己的不稳定，主结论不成立。

## 四、分层：主表里有一半配对根本没换 prompt

主表的 FR 把两类配对混在一起：**证据（检索到的边）没变**的，prompt 逐字相同 → 缓存命中 → 答案必然相同；**证据变了**的，才是真正的「图变了」。不拆开，翻转率会被前一类稀释。

| 分支 | 证据未变（题/翻转） | 证据变化（题/翻转） |
|---|---|---|
| refine | 94 / 0 | 6 / 3 |
| restrict | 51 / 0 | 49 / 14 |
| merge | 42 / 0 | 58 / 14 |
| split | 50 / 0 | 50 / 12 |
| all | 14 / 0 | 86 / 26 |
| **合计** | **251 / 0** | **249 / 69** |

- 证据未变 **0/251 = 0.000**：这是缓存保证的 0，**不是**模型的稳定性
- 证据变化 **69/249 = 0.277**：这才是「图变更咬到证据」时的真实翻转率
- 与噪声 0.180 对照：真实效应高出 **+0.097**（近似两比例检验 z=2.03、p=0.042；**未配对、两边题重叠**，这个 p 值偏乐观，只能当量级参考，不能写成「显著高于噪声」）

**这一节改变了主结论的写法**：不能直接说「FR=0.138」，必须写成「证据变化子集上 FR=X，同一 prompt 重采样的噪声为 Y」。

> 注意：这里只测了 v1 的噪声（反事实），v2 的噪声只在 all 分支各测了一组，见第一节。两类图的噪声未必相同，论文里应写「底噪在 v1 上实测为 X」。
