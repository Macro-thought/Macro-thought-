# metrics —— 翻转指标

只评「该变的变没变」，不评「答得对不对」。所以不需要 gold，也**不用 accuracy**。
所有指标都由 `metrics/score.py` 从 jsonl 直接算，不 import `baselines/`、`labels/`、`ops/`
（否则被测实现的 bug 会同时污染信号和尺子）。

## 四个指标（一句话 + 分母）

| 指标 | 一句话定义 | 分母 |
|---|---|---|
| **FR** 答案翻转率 | v1 与 v2 的答案不同的比例。整体抖动水平，不分好坏 | 两版**都有预测**的题 |
| **FFR** 误翻转率 | 本该 `stable` 的题，答案却变了的比例。**核心指标，越低越好** | `should=stable` 且两版都有预测的题 |
| **MFR** 漏翻转率 | 本该 `flip` 的题，答案没变的比例。越低越好 | `should=flip` 且两版都有预测的题 |
| **UAR** 不可答误答率 | 该拒答的题，v2 仍给出非空答案的比例。越低越好 | `should=unanswerable` 且 v2 有预测的题 |

分母都是「有效观测」，不是「全部题」。缺一侧预测的题既不能算变、也不能算没变，
所以一律从分母剔除，并单独计数（`missing_v1` / `missing_v2` / `missing_both`）打到报告脚注。
**每格都印 n**：`0.278 (n=18)` 和 `0.278 (n=3)` 是两个世界。

## 为什么不用 accuracy

accuracy 把「稳定但答错」和「该翻没翻」混成一个数，而本实验要区分的恰恰是这两件事。
而且 v2 图本来就会改变正确答案（该翻的题答对 v1 的答案反而算错），
accuracy 会奖励「什么都不变」的方法——正好和实验目的相反。这里没有 gold，
只有 `should`。

## 答案规范化

字符串去首尾空白、压缩内部连续空白、大小写不敏感；列表逐元素规范化后排序比较；
`""` / `[]` / `None` 统一视为「未作答」。数值额外统一（`188` = `188.0`）：
这是写法差异，不统一会把 FR 凭空抬高一截。注意「有答案 → 未作答」仍**算一次翻转**
（对同一方法来说，拒答本身就是行为变化），但会单独计数，因为这类翻转对噪声极敏感。
报告脚注里的「其中空答翻转=k」就是它。

## 噪声底噪对照

单换一张图，任何方法都会抖一点。所以把 `b1_text`（文本基线）在 v1/v2 上的 FR 当底噪，
对每个方法给出 `Δ = FR − 底噪`、差值的 95% 区间（Newcombe 的 Wilson 混合法，
不是两个单侧 Wilson）和两比例 z 检验的 p 值（未做连续性校正）。没有 `b1_text` 时整节跳过并说明。
**只有明显高于底噪的 FR 才算信号。**

## n 多少才敢解读

**n < 10 不要解读。** 报告里这样的格子带 `†`。理由：n=10 时比例的 Wilson 区间
宽度约 0.53——两个方法在这种样本量下的任何差距都落在噪声里。
单看某个格子 n=4 的 0.500，和抛 4 次硬币没有区别。
同理，底噪自身 n < 10 时，噪声对照表的 Δ 也不可信（会标注）。
另外若某格 missing 占比很高，该格只代表一小撮题，不能外推。

## 用法

```bash
python metrics/score.py --qa data/qa_smoke.jsonl \
    --pred baselines/out/bfs2_v1.jsonl --pred baselines/out/bfs2_v2.jsonl \
    --out reports/metrics.md --json reports/metrics.json
python metrics/score.py ... --branch split      # 只看一个分支
python metrics/tests_smoke.py                   # 手算值 vs 脚本值，全绿才算通过
```

关于连接：qa 的 qid **只在分支内唯一**（真实数据是 Q001–Q019 × 5 个分支），
而预测行通常只有 `meta.graph`。脚本会先把每个方法的预测解析到唯一分支
（`meta.graph` → 分支的映射，v1 的 `graph_v1.json` 被三个分支共用时用该方法的 v2 图判定），
解析依据打印在报告第 0 节。解析不了的行会被丢弃并计数，不猜。
若你的 pred 行带 `branch` 字段，会直接采用（最稳）。
